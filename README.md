# mem0 + memU 双轨记忆架构 Demo

## 🎯 架构设计理念

**双轨记忆架构**模拟人类大脑的记忆系统：

| 记忆系统 | 对应模块 | 特点 | 存储形式 |
|---------|---------|------|---------|
| **短期工作记忆** | mem0 | 快速检索、语义匹配、近期对话 | 向量数据库 |
| **长期结构化记忆** | memU | 深度理解、分类归档、总结提炼 | Markdown 文件系统 |

## 🧠 双轨分工

### mem0 - 短期工作记忆
**职责：**
- 存储最近 N 轮对话（滑动窗口）
- 语义相似度快速检索
- 临时事实记忆
- 上下文补全

**触发时机：**
- 每次对话自动写入
- 查询时优先检索
- 阈值：最近 50 条 / 7 天

### memU - 长期结构化记忆
**职责：**
- 提取用户画像（偏好、习惯、目标）
- 分类归档（个人信息、知识、关系、偏好）
- 深度总结提炼
- 跨会话知识积累

**触发时机：**
- 每累计 10 条对话异步触发
- 用户手动触发
- 定时任务（每日总结）

## 🔄 工作流程

### 1. 对话写入流程

```
用户输入
    ↓
DualTrackOrchestrator.write()
    ├─→ 立即写入 mem0（向量存储）
    └─→ 判断阈值 → 累计 N 条后，异步触发 memU 提取
                          ↓
                    memU 分类归档
                          ↓
                    生成 Markdown 文件
```

### 2. 记忆检索流程

```
用户查询
    ↓
DualTrackOrchestrator.search(query)
    ├─→ mem0 向量检索 (top_k)
    │    返回: 最近相关对话
    │
    └─→ memU 关键词检索
         返回: 分类结构化知识
                          ↓
                    Fusion 融合两者结果
                          ↓
                    返回统一格式上下文
```

## ✨ 核心创新点

1. **冷热分层**：热数据放 mem0 快速访问，冷数据放 memU 深度归档
2. **异步同步**：memU 提取不阻塞主对话流程
3. **互补检索**：向量相似度 + 关键词分类 = 更全面的上下文
4. **成本最优**：只在必要时调用 LLM 做深度提取，平时走向量数据库
